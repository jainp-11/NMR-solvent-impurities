# NMR-solvent-impurities
NMR Impurities identifies trace solvent impurities in NMR spectra. Pick a deuterated solvent to see ¹H and ¹³C shifts of 45 common impurities, with simulated spectra, splitting and J values, peak lookup by ppm, solvent comparison, and PNG/SVG/CSV export. Data: Fulmer et al., Organometallics 2010.
